# Bildquellen: Sieges-Pool

Vorlagen für die Szenen auf oberster Ebene von `ascii/` (Sieges-Pool von `/finish`). Wie bei
[Life of Vegeta](../life_of_vegeta/SOURCES.md) stammen sie aus dem [Dragon Ball Wiki (Fandom)](https://dragonball.fandom.com/),
sind urheberrechtlich geschützt (Akira Toriyama / Bird Studio / Shueisha / Toei Animation / Bandai Namco / Funko)
und deshalb **nicht** im Repo. `python3 fetch_images.py` lädt sie lokal nach `images/victory/` (git-ignoriert).
